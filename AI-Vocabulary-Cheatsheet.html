AI Vocabulary — Cheatsheet

The words behind LLMs, RAG, Agents, MCP & modern AI systems · v1.1-beta · 2026 · keep as a reference

Foundations — the building blocks
Artificial Intelligence AIMachines doing things that used to need human intelligence — deciding, recognising, generating.
Machine Learning MLAI that learns patterns from data instead of being hand-coded with rules.
Deep LearningML using multi-layer neural networks; powers modern vision, speech and language.
Neural NetworkConnected "neurons" in layers, loosely modelled on the brain, that learn by adjusting weights.
Generative AIAI that creates new content — text, images, audio, video, code — not just sorts or scores it.
The model & language
Large Language Model LLMA transformer trained on huge text to predict the next token; the engine behind ChatGPT, Claude.
Small Language Model SLMA smaller, cheaper, faster model tuned for speed, cost, or a specific task.
ModelThe trained system (the weights) that makes predictions or generates content.
TokensThe chunks of text a model reads/writes — roughly words or word-pieces ("playing" → "play"+"ing").
Context windowThe model's working memory — the max tokens it can consider at once (input + output). Finite.
TemperatureThe creativity dial — low = predictable/consistent, high = varied/creative.
HallucinationA confident but wrong answer — the model optimises for plausible text, not truth, and never self-checks.
PromptThe instruction or input you give the model to get a response.
Prompt engineeringShaping the prompt — role, examples, format, steps — so the model gives better, more useful output.
Chain-of-thought CoTPrompting the model to reason in steps before answering; improves logic and maths.
Training the model
DatasetA collection of data used to train or test a model.
Data trainingFeeding data to a model so it learns patterns and behaviours.
Fine-tuningFurther-training a pretrained model on a smaller, focused dataset to specialise it.
RLHFReinforcement Learning from Human Feedback — tuning with human preferences so it's helpful and safe.
Knowledge & retrieval (RAG)
RAG🖼️Retrieval-Augmented Generation — search your documents first, then answer grounded in them. The common fix for hallucination.
Embeddings🖼️Numeric "meaning" vectors for text; similar meanings sit close together — enabling search by meaning.
Vector databaseStores embeddings and finds the most similar — semantic search (Pinecone, Weaviate, pgvector).
Chunking🖼️Splitting documents into smaller searchable pieces before embedding them.
Hybrid search🖼️Combining keyword search with semantic (vector) search for better recall.
Reranking🖼️Re-sorting retrieved results by true usefulness before passing them to the model.
Action & agents
Tool callingLetting the model use external tools/systems — run code, query a DB, call an API.
Function callingThe model emitting structured arguments to invoke a specific function.
Memory🖼️Storing useful information across steps or sessions so an agent doesn't forget.
AI agent🖼️An LLM that takes actions in a loop (Think → Act → Observe) until a task is done — not just answers.
Agentic AI🖼️Self-directed AI that plans, reasons and executes multi-step tasks toward a goal.
Agentic workflowA structured flow where the AI plans and executes steps, usually with human checkpoints.
Multi-agent system🖼️Several specialised agents collaborating and coordinating on a task.
Connecting agents — protocols
MCP🖼️Model Context Protocol — open standard connecting agents to tools, data & context. "USB-C for AI" (Anthropic).
A2A🖼️Agent-to-Agent — a protocol for agents to discover each other and coordinate (Google).
A2UIAgent-to-User-Interface — an emerging protocol for agents to render and drive UIs.
Production & operations
PlannerBreaks a goal into smaller, ordered steps.
Evaluator🖼️Checks whether the output is good enough — often an "LLM-as-judge."
Guardrails🖼️Safety, policy and quality controls that constrain what the AI can do or say.
Observability🖼️Logging, tracing and monitoring of AI behaviour in production.
AutomationUsing AI to perform repetitive tasks without human input.
Applied AI
Natural Language Processing NLPAI that understands and works with human language — text and speech.
Computer VisionAI that sees and understands images and video.
Voice AIAI that recognises and responds to spoken language.
Diffusion modelsThe tech behind most image generators — learn to remove noise, turning randomness into an image.
PersonalizationAI tailoring content, recommendations or experiences to an individual.
Responsible AI
AI EthicsRules and practices ensuring AI is fair, transparent and used responsibly.
