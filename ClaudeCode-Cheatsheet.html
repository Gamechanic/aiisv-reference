Claude Code — Cheat-Sheet

Anthropic's agentic coding tool · for the AI SDLC course

01 At a glance

Claude Code is Anthropic's agentic coding tool — text in → actions performed.
  • It reads/edits files, runs commands & tests — not just chat.
  • Surfaces: CLI (terminal) · IDE (VS Code, JetBrains) · Desktop app (Mac/Windows) · Web (claude.ai/code).
  • You steer & approve — the agent does the work.

02 The agent loop

Think → Act → Observe, repeated until the task is done.
  • Plan Mode: it proposes a plan (read-only) before acting.
  • You review and approve each step.

03 CLAUDE.md — the constitution

Project rules/memory at the repo root, auto-loaded every session.
  • Holds: standards, stack, conventions, key commands, guardrails.
  • Also a user-level ~/.claude/CLAUDE.md (applies everywhere).
  • Tip: press # to quickly add a memory.

04 Memory

Persistence across sessions, so the agent doesn't relearn each time.
  • Project CLAUDE.md, user memory, and a file-based memory the agent can recall.
  • It remembers decisions & conventions instead of starting fresh.

05 Skills (SKILL.md)

Reusable capabilities packaged as a folder with a SKILL.md file.
  • Frontmatter: name, description; body: instructions; optional scripts/assets.
  • Auto-invoked when the description matches the task.
  • Live in .claude/skills/.

06 Subagents

Spawn parallel/independent agents for fan-out work.
  • Good for search, review, multi-file edits — keeps the main thread focused.
  • Custom agent types live in .claude/agents/.

07 Hooks

Run shell commands on lifecycle events via settings.json.
  • Events e.g. PreToolUse, PostToolUse, Stop.
  • Automate linting, formatting, guards.
  • The harness runs them, not the model.

08 MCP (Model Context Protocol)

Connect external tools & data via MCP servers — "USB-C for AI."
  • Configure in .mcp.json / settings.
  • The connected tools become available to the agent.

09 Slash commands

Type-ahead commands inside a session.
  • /help · /clear · /model · /config · /agents · /hooks · /permissions · /init · /review
  • Custom commands = Markdown files in .claude/commands/.

10 Permissions & safety

Permission modes: prompt / allow / deny.
  • Allowlists in settings.json.
  • Plan Mode is read-only; sandboxing for risky commands.
  • Approve diffs before they land.

11 Reviewing work

Review focused diffs, not 1000-line dumps.
  • Accept/reject changes.
  • /code-review for a deeper pass.
  • The human verifies.

12 AGENTS.md

An emerging cross-tool standard for agent configuration.
  • Shared across coding agents.
  • Complements CLAUDE.md.
